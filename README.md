# 🛍️ E-Commerce Web Application

An elegant and fully responsive **E-commerce web application** built using the MERN stack.  
This project allows users to browse products, manage carts, place orders, and handle admin operations such as product management.

## 📖 Overview
This project is a modern E-commerce platform with both **user and admin functionalities**.  
It includes authentication, product filtering, cart management, and order placement features.

---

## ✨ Features

### 🧍 User Side
- Browse products by category
- Add/remove items from the cart
- Apply discounts and view total price
- Secure user authentication (JWT)
- Place and track orders

### 🛠️ Admin Side
- Admin login and authentication
- Add, update, and delete products
- Manage user accounts and orders

---

## 🧰 Tech Stack

**Frontend:**
- React.js (Vite)
- Redux Toolkit
- Axios
- Tailwind CSS / Material UI

**Backend:**
- Spring Boot (Java)
- MySQL Database
- JPA / Hibernate

**Deployment:**
- Frontend: Vercel  
- Backend: Railway
